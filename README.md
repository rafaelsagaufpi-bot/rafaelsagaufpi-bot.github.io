# Rafael Ferreira — Academic Website

A minimal, responsive, static academic website in English, ready for GitHub Pages.

## Files
- `index.html`: website content
- `styles.css`: design and mobile layout
- `script.js`: automatically updates the copyright year

## Publish for free using GitHub Pages
1. Sign in or create an account at https://github.com/.
2. Click **+** (top-right) > **New repository**.
3. For the shortest address, name the repository **YOUR_USERNAME.github.io**, replacing YOUR_USERNAME with your actual GitHub username. Select **Public** and create the repository.
4. Click **Add file** > **Upload files** and upload `index.html`, `styles.css`, and `script.js` directly to the repository root (not inside a folder). Commit the changes.
5. Go to **Settings** > **Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
6. Wait a few minutes and visit `https://YOUR_USERNAME.github.io/`.

If you instead use a repository named `academic-site`, the address will be `https://YOUR_USERNAME.github.io/academic-site/`.

## Customize before sharing
- Replace the unverified bibliography placeholder with actual published works and DOI links.
- Add your preferred public contact email and verified GitHub, ORCID, Google Scholar, and CV links.
- Review the biography and project descriptions for accuracy.
- To change text, edit `index.html` and commit the changes; GitHub Pages will redeploy.

No hosting fee, domain purchase, or paid software is required for this basic site. GitHub Pages on GitHub Free supports public repositories. GitHub account and public repository are required.
